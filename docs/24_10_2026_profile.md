## Сверено по Figma

### Toggle (K-DS 517:1143)

- Трек 40×20, radius full; бегунок 24×16, полный радиус (кламп к высоте).
- Off: бегунок с отступом 2 слева; On: отступ 2 справа; ход 12pt — снято
  пиксельно по рендерам мастеров (MCP-код даёт pl/pr, которые не сходятся
  в трек 40: `pl2+knob24+pr16=42`, растру поверил).
- Цвета — переменные: off `#b8d3b9`, on `#35916b`, бегунок #ffffff.
- Анимация: Reanimated `withTiming` 200 мс (задача: 180–220), ход и цвет
  трека на UI-треде. Быстрые повторные нажатия — value ретаргетится с
  текущего положения без скачков. Без spring/масштабирования.
- Тап: Pressable 40×20 + hitSlop 12 → 64×44 (норма 44dp).
- Доступность: `accessibilityRole="switch"`, `accessibilityState.checked`,
  label «Тёмная тема» задаёт вызывающий экран.

## Ограничения

1. Toggle на этом этапе управляет только своим состоянием; тема, настройки
   «Оформление» и сохранение выбора — вне задачи (§3 ТЗ).
2. Кольцо Avatar: iOS рендерит выходящую за 80-бокс обводку; на Android
   контент родительского View клипается — в обёртке 80×80 кольцо по 4px с
   каждой стороны обрежется. iOS-first; при появлении Android-приёмки —
   пересчитать раскладку (аватар станет 88 по габариту).
3. Шрифт Onest в RN подключен вариативным TTF (вес 450 через числовой
   fontWeight — прецедент `typography.ts`); «%username%» — литерал макета K.
4. Weight «Тёмной темы» = 450 по привязке узла (Onest/Body); Title1 — 700.
5. Dark-палитра аватара/тумблера в K-DS не подтверждена (см. `_x/27.md`
   и memory avatar) — экран светлой темы, архитектура готова к Dark.
