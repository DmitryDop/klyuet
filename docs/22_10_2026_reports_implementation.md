## 2. Реализовано

**Создание отчёта** (`/report-form/[placeId]`, K 206:9625…):
- место привязано по `placeId` (заголовок + «Публикация в выбранной точке»); поля места в отчёт не копируются (§3);
- «Как прошла рыбалка?» — обязательные чипы 44; «Без улова» скрывает выбор рыбы и не публикует видов (§4.2);
- дата рыбалки: поле дд.мм.гггг → шторка с системным барабаном (display=spinner) по контенту: «Применить» подставляет дату, синхронизирует чипы, закрывает; будущие даты запрещены (§4.3–4.4);
- способ ловли (чипы, deselectable), снасть (шторка, радио, тап = выбор + закрытие), приманка (Input 48), «Что происходило?» (Textarea 120), фото («Добавить фото» dash 8/gap 4; ActionSheet: камера/медиатека/файлы; реальный URI; удаляемый circle-xmark);
- валидация по нажатию: кнопка всегда активна; «С уловом» без видов — Error-подсветка поля (2px danger + подпись «Это поле нужно заполнить») + скролл к ошибке;
- публикация: лоадер кнопки (свой Spinner), повторный submit и правка заблокированы; успех → replace на созданный отчёт + тост «Отчёт опубликован» у нижней границы (Дмитрий, 22.10);
- выход: beforeRemove-предохранитель; dirty-модалка «Выйти без сохранения?» (224:6017): Остаться / Выйти, крестик = Остаться (§6);
- ошибки публикации (225:6113): «Вернуться к отчету» + «Повторить»; поля и фото переживают ошибку.

**Редактирование** (K 160:8719):
- pen в тулбаре своего отчёта → та же форма с предварительными значениями;
- сохранение обновляет ту же сущность (repo.updateReport, не создаёт новую); тост «Изменения сохранены»;
- своя модалка ошибки «Не удалось сохранить изменения» (228:8682);
- у чужого отчёта элементов правки нет (§5, §2).

**Шторка «Все отчеты рыбака»** (по navigation.md 22.10; K 366:4940, 366:5145):
- из чужого отчёта: Sheet со списком отчётов автора (все места, сортировка §7);
- полный отчёт открывается внутри той же модалки; список остаётся смонтирован — возврат стрелкой сохраняет прокрутку, дублей нет;
- крестик закрывает всю Sheet из любого состояния; исходный отчёт A остаётся с состоянием;
- «Перейти в место» из модального отчёта: dismissAll + push — Карта → карточка места, Назад → карта (§3);
- у своего отчёта кнопки нет (§2).

**Состояния** (reports.md §8):
- единый Toast-компонент (K-DS 316:1799), ToastHost в корне автогора; ~3 с, без кнопок; ошибки — модалками;
- Modal Card (K-DS 308:1355): иконки circle-info/attention, Title1/Body, два действия, крестик;
- Button: K-DS Disabled (opacity 0.4) и Loading (спиннер, лейбл скрыт, submit заблокирован);
- skeleton списков (SkeletonCards) и деталей (SkeletonReportDetails), мягкая пульсация через Reanimated; ошибки загрузки — состояние с «Повторить» (report, place-reports);
- списки обновляются при возврате: useFocusEffect в place card / place-reports / author-reports (§2).

**Чек-лист приёмки** — большая часть прошла в живых прогонах Дмитрия (22.10): форма (чипы, шторки на Live-выборе, барабан с «Применить», error-подсветка со скроллом, focused-границыы, dash-кнопка фото, ActionSheet с правами, панель CTA: поток/над клавиатурой, тост снизу). Осталось прогнать:
1. Публикация → созданный отчёт + тост «Отчёт опубликован»; списки места обновлены при возврате.
2. Правка: pen → изменения → «Сохранить отчёт» → тост «Изменения сохранены»; возврат без изменений — сразу.
3. «Выйти без сохранения?»: Остаться / Выйти, тап вне, крестик, уезжание вниз.
4. Шторка «Все отчеты рыбака»: список → полный отчёт → назад к списку (прокрутка), крестик, «Перейти в место» (Назад → карта).
5. Skeleton/ошибки с «Повторить» (синтетически — см. §6).
