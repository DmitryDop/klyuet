## Расхождения и ограничения

- **Удаление места:** сценарий в приложении не реализован (нигде нет) — критерий ТЗ §7 «исчезает после удаления» неприменим; проверен только принцип запрета редактирования при отчётах (сущ. правило place-form/карточки, не тронуто).
- **Стоимость платных мест** в модели отсутствует — инфолиня «Платное место» без суммы (как во всей карточке места).
- **Состояние ошибки списка** (journal.md §6: ошибка + «Повторить») не построено: демо-репозиторий не возвращает ошибок — dead-код; появится вместе с реальным бэкендом.
- Skeleton только при первой загрузке вкладки (быстрый демо-репо, ~сотни мс).
- Кнопки «Добавить» — primary с Pressed (K-DS Button 165:16) через общий `Button`; pressed-реакция белых карточек журнала не нарисована (K-DS InfoRow вариантов состояния не задаёт).
- Карты демо-данных: у «Моих мест» все публичные частные случаи (private) создаются сценарием «+» — карточка с «· Примерное место» проверяется созданием.

Проверки §10 п.1–5, 8–10 — на устройстве. Серверы/сим не запускались; commit/push — по решению Дмитрия.
