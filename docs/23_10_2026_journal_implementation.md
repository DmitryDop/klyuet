## Дополнение 23.10: сценарий редактирования места (карандаш)

Сценарий Дмитрия (23.10): карточка → карандаш → шаг 1 (точка на карте, координаты можно менять) → шаг 2 (форма с заполненными полями) → «Сохранить изменения» → карточка обновлённого места. Изменения применяются ТОЛЬКО при финальном сохранении; закрытие сценария оставляет исходное место без изменений.

Реализация (переиспользование сценария создания, без новых интерфейсов):

- `src/data/place-create-store.ts` — `PlaceCreateDraft.editPlaceId?: string` — маркер редактирования; шаги 1/2 работают с черновиком как при создании.
- `src/data/repo.ts` — `updatePlace(id, draft)`: единовременное применение; представление пересобирается по точности (приблизительное → округлённый центр области + прежний радиус, точное → координата); `createdAt` не меняется; до сохранения исходное место без изменений.
- `src/data/add-request-store.ts` — интент несёт место (или null для «Добавить» из журнала).
- `src/app/place/[id].tsx` — карандаш (можно только при отсутствии отчётов): интент + переход на вкладку карты; шторка шага 1 открывается поверх.
- `src/app/(tabs)/map.tsx` — приём интента: `clear + ensure + префилл` шага 2 + `editPlaceId`; камера прицеливается к точке места после первого замера шторки (обратный сдвиг: прицел = точка места, та же арифметика §8); при обычном создании (запрос без места) — центр карты, как раньше.
- `src/app/place-form.tsx` — режим редактирования: тулбар «Редактирование места» (шаблон «Подробнее о месте»: назад + центр), CTA «Сохранить изменения», ошибка «Не удалось сохранить изменения», тост «Изменения сохранены» (journal.md §6); снятие формы гасит edit-черновик (незавершённое редактирование ничего не сохраняет). Координатная шапка с pen (→ шаг 1) работает как раньше.

Решения без утверждённого макета (реализовано по компонентам, пометка): заголовок тулбара и CTA-текст — по формулировке Дмитрия; тост/ошибки — по прецеденту формы отчёта и journal.md.

Ограничения сценария редактирования:
- при тапе карандаша живой незавершённый черновик СОЗДАНИЯ перезаписывается редактированием (перезапись без диалога — демо-сессия, редкий крайний случай);
- кнопка геолокации шага 1 остаётся «возврат в посёлок Восход» (фейк-гео) — в редактировании собьёт редактируемую позицию; не тронуто (существующее поведение);
- переход `router.navigate('/(tabs)/map')` из карточки: карточка остаётся в истории навигации карты — после отмены шага 1 «Назад» с карты уводит в прежнюю карточку места (известная ветвь, navigation.md допустим);
- радиус области приблизительного места редактированием не меняется (полигона в черновике нет).
