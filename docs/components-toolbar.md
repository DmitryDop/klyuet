## Утверждённая геометрия (iPhone, Default)

- Контейнер: `px 16` (spacing/md), `py 8` (spacing/xs), высота 60 = кнопка 44 + 8 + 8.
- Кнопки — `button-ui` 44×44 (radius 12, bg `--color-surface-default` = rgba(255,255,255,0.90), иконка 24): вариант с тенью — поверх карты, Shadows=No — в тулбарах.
- Заголовок — `Onest/Headline` 16/20 · 600, `--color-text-primary`, одна строка; подзаголовок (Two Line) — `Onest/Subheadline` 12/14 · 500, `--color-text-secondary`.
- Фон самого компонента не задан — на экранах фон = `--color-bg-primary`.

## Правила Дмитрия (21.10.2026)

1. **Заголовок/подзаголовок всегда по центру панели** — при появлении/исчезновении левой или правой кнопки не двигаются (эталонное поведение — example 409:465: титул центрируется `top-1/2`, все три примера — с кнопками и без).
2. Длинное название обрезается **ellipsis внутри фиксированной зоны 255** (K-DS 218:405 / 218:469).
3. Панель тулбара, появляющаяся при скролле **карточки места, собрана не из компонента Toolbar** — собственное решение; высота 60: кнопка `top 8` + 44 + нижний отступ 8 (симметрично), кнопки внутри — ButtonUi Shadows=No.

## Правило реализации (RN)

Абсолютный центр заголовка задавать **full-width обёрткой** `left: 0 / right: 0` с внутренней зоной 255. Не использовать `left: '50%'` + `marginLeft` в контейнерах с горизонтальным паддингом: в RN процент `left` рассчитывается от padding-бокса, центр уезжает на половину паддинга (баг был подтверждён на симе, 21.10.2026).

## Реализация в проекте

- `src/components/button-ui.tsx` — кнопки внутри тулбаров (44×44, Shadows Yes/No);
- `src/app/place/[id].tsx` — панель тулбара карточки места (высота `insets + 60`);
- `src/app/report/[id].tsx`, `src/app/author-reports/[id].tsx` — тулбары экранов отчётов (Default / Two Line).
