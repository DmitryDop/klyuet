## Реализованная механика

1. Шестерёнка (с любого таба) → переход на карту + открытие шторки.
2. Текущий вид отмечен radio (selected state по K-DS).
3. Тап по варианту → режим применяется мгновенно (prop `mapType` того же
   экземпляра MapView) → шторка закрывается автоматически.
4. Закрытие (✕/скрим/свайп/системная назад) — режим не меняет.
5. Повторное открытие показывает актуальный вариант (store).
6. Выбор сохраняется при навигации (store) и между перезапусками
   (AsyncStorage; load в корневом layout до первого рендера карты).
7. Не затронуты: `+`/сценарий добавления, навигация, метки/кластеры,
   области, фильтры, поиск, карточки, журнал, тема (вид карты независим
   от темы; светлая MapKit-тема остаётся).

## Поддержка режимов SDK

react-native-maps 1.29.11 (Apple Maps/MapKit, устройство без ключей):
`mapType` — `standard` (Схема), `satellite` (Спутник), `hybrid` (Гибрид,
снимки + подписи). Все три — нативные режимы MapKit, подмена/новый SDK
не потребовались.

## Известные ограничения

- Подписи MapKit на Спутнике отсутствуют, Гибрид содержит подписи — поведение
  SDK, не обход.
- AsyncStorage v3 в Expo Go — подключен через автолинк; если при приёмке
  на устройстве возникнут ошибки хранилища — проверить нативный билд
  (dev-client сборка может потребовать prebuild).
- В шторке нет Bottom Action (hidden в макете) — подтверждение не предусмотрено
  ТЗ §3.
- Скриншоты/кропы временных проверок удалены после приёмки тапов не требуется:
  рендер подтверждён, файлы вычищены (решение Дмитрия 24.10).
